# 躲障碍：双排穿门

在现有三种路线中加入每局四轮穿门。预警约在第 8、20、32、44 秒开始，预警 1.5 秒后出现侧移双门、阶梯三门、折返三门和四排星夜回旋。每排有星星缺口，相邻两排缺口相邻；预警高亮第一缺口并显示阵型名称，在开启音效时播放一次提示音。

预警和穿门期间暂停新随机障碍，已出现的障碍继续移动。各排相隔 250 个场景单位，保留移动窗口；通过后恢复随机路线。

整轮不损失生命，获得 70/80/90/100 分和 2 点护盾充能。护盾抵挡不扣生命，仍算无伤。撞到后正常继续，不会立即结束整局；原三次失误和 60 秒规则保留。

`CourseWaves.ts` 只管理波次时序、排布与奖励；`DodgeGuard.ts` 管理充能与保护；`DodgerGame.ts` 接入现有移动、碰撞、绘制和结算。全部状态仅属于本局，不改变存档格式。

本轮只完成源码复核和构建；缺口节奏、不同路线难度和触屏操作尚待试玩验证。
