# 弹珠远征

在大厅进入「弹珠远征」。左右方向键 / A、D 控制挡板，鼠标或手指按住画面拖动也可控制；点击、空格或下方发射按钮发射。挡板不同位置的反弹角度不同。

## 六关与选择

晨光花园、珊瑚回廊、水晶矿洞、风之阶梯、星海环城、黯星之核使用不同砖块排布。清空一关后选择永久升级：挡板 +24（最高 216）、伤害 +1（最高 3）或生命 +1（最高 5）。到达上限的选项不会消耗机会；完成选择后下一关待发射。第六关含 8 点生命的核心砖，清空全部砖块通关。

三次初始发射机会；全部弹珠掉落才损失一次机会，残存砖块保留。没有局内倒计时。

| 内容 | 效果 |
| --- | --- |
| 普通砖 | 1 次基础伤害击碎 |
| 装甲砖 | 2 点生命，显示剩余值 |
| 爆破砖 | 破坏后对周围砖块造成 1 伤害，可引爆下一块 |
| 水晶砖 | 更高分数并掉落道具 |
| 加宽道具 ↔ | 挡板暂时加宽 48，持续 12 秒 |
| 分裂道具 ❖ | 从存活弹珠分裂，场上最多 5 颗 |
| 底线护盾 ◇ | 接住一次即将掉落的弹珠，最多储存 3 次 |

升级可点击选择或左右切换、空格确认。支持全局暂停、重开、最高分和 v7 备份（v6 已纳入弹珠纪录）；进行中的远征暂不存档。道具按关卡与砖块编号固定掉落，不含付费或随机抽奖。

## 结构与实际检查

`Stages.ts` 为六关和升级数据；`BreakerModel.ts` 管理小时间步物理、砖块、弹珠和道具；`BreakerRenderer.ts` 绘制；`BreakerGame.ts` 适配现有 MiniGame。没有新动画循环或独立监听器。

已通过 TypeScript 与生产构建，尚未运行自动化或实际玩法测试。反弹手感、关卡耗时、多球碰撞和触屏升级选择仍需实际验证。
