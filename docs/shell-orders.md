# 贝壳消消乐：潮池订单

在开局的「玩法」中选择经典寻宝或潮池订单。默认仍为经典模式，原有 60 秒计时、三消、四连造星、双星清屏和连锁规则保留。

订单模式按顺序完成：6 枚贝壳（+80）、8 枚珍珠（+120）、10 条小鱼（+180）。只统计当前订单、实际从棋盘移除的目标物件。四连保留星星、五连保留虹贝，不计为移除；普通消除、爆炸和连锁均可推进当前订单。

五连生成虹贝。虹贝与普通物件交换会清除对方的同色物件，并引爆清除范围内的星星；两枚虹贝交换可清屏。虹贝被普通消除或星星引爆时，清除自身底色对应物件。一次消除最多保留一个新特殊物件，优先最长的连线。

一次消除只结算当前订单，溢出数量不转给下一单；下一次连锁可继续推进新单。全部订单完成后继续冲分到计时结束。没有通过强制掉落目标物件来保证完成，难度尚待试玩调整。

画面顶部和公共状态栏展示当前目标，左侧展示订单顺序；目标物件带金色小点。结算显示完成单数和加分。停留提示在订单模式中优先评估能实际推进当前目标的交换，并考虑造星；经典模式仍提示第一个合法交换。提示只作建议，不强制玩家操作。

`ShellOrders.ts` 只处理进度与奖励，不依赖 DOM 或随机数；棋盘在移除物件前提供实际清单。`SpecialClears.ts` 处理爆炸传递，游戏类负责现有流程与绘制。订单不写入持久存档，重新开始会重置。

两种模式共用现有本机最高分，订单奖励会影响分数可比性；未建立独立排行。当前只完成源码与构建检查，没有运行玩法测试。
