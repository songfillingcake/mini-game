# 推箱小岛

方向键 / WASD 移动，或点人物相邻的格子。箱子只能推，不能拉；所有箱子到达金色目标格后，本岛完成。手机有四方向按钮。

- 第一推、双星并行、交错小径、绕过石墙、借道前行五组布局，随后为其水平镜像，共十岛；不是十张独立设计的地图。
- 空格或「撤回」可撤回最近动作，最多保留本岛最近 300 步；重置回到本岛初始状态。
- 箱子进入非目标的石墙角落时给出提醒；没有穷尽所有死锁判断，可自行撤回调整。
- 本岛完成后，点击下一岛或按空格继续。已结算小岛不能通过撤回重复领分。
- 每岛 200 基础分，另加最多 100 的少步奖励。没有体力、倒计时或收费。

最高分纳入 v7 存档备份，导入旧备份不会删除现有推箱纪录。进行中地图、撤回历史暂不持久保存，离开后重新开始。

## 结构与范围

`Islands.ts` 放布局；`SokobanModel.ts` 放推箱、快照、撤回和计分；`SokobanRenderer.ts` 放画面；`SokobanGame.ts` 复用大厅输入与主循环。
