# 猫猫钓鱼：钓点选择

出发前可在已选海域内选择三个钓点，不需要消耗贝壳：

| 钓点 | 鱼群权重 | 收线 |
| --- | --- | --- |
| 开阔水面（默认） | 原规则 | 原规则 |
| 芦苇浅滩 | 常见 ×1.4，稀有/传说 ×0.8 | 绿区两侧各扩大 0.02，时限 +1 秒 |
| 深水外沿 | 常见 ×0.75，稀有/传说 ×1.45 | 主拉力振幅 ×1.08，时限 −1 秒 |

权重倍率影响抽取相对机会，不是固定概率，也不保证稀有鱼出现。钓点与鱼饵、天气、昼夜、海域奇遇共同作用；不解锁其他海域，不绕过奇遇鱼的日期条件。

选择在开局锁定到本局；结算和场景显示实际使用钓点。选择暂不写入浏览器偏好或备份，不修改现有鱼获、奖励与存档结构。

`FishingSpots.ts` 管理参数和权重；游戏类接入鱼群抽样、拉力、时限。绿色区域的绘制与真实判定使用相同钓点扩展量，虚线趋势也读取同一拉力函数。

2026-10-30 增加精准稳线：在绿区中央三分之一完成一次有效拉线后，接下来一秒的拉力相位以 65% 速度推进。持续更新相位，不跳动指针；虚线预估也考虑稳线持续时间。不会额外送鱼、加时或更改收线章标准，仍需三次有效拉线。时限继续按真实游戏时间消耗。
