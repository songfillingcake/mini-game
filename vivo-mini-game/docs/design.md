# 捏捏星球 · 设计与数值

## 1. 体验目标

一句话：**「开会摸鱼时打开，三秒后手指舒服了，两分钟后心甘情愿关掉。」**

由此推出三条不可动摇的原则：

1. **零门槛**：打开即玩。没有登录、主菜单、教程弹窗、加载条。
2. **零失败**：不存在「死了」「输了」「时间到」。唯一的负反馈是「没按中」——而且也不算错。
3. **可中断**：任何时刻切后台、锁屏、退出，都不丢进度（3 秒节流落盘）。

## 2. 核心循环

```
        ┌─────────────────────────────────────────┐
        │                                         │
   按住星球 ──► 软体凹陷 / 星尘 / 音高 / 震动 ──► 松手回弹
        │                                         │
        └──► 星尘 +1 ──► 攒够阈值 ──► 解锁新材质 ──┘
                  ▲
                  └── 呼吸窗口内按下：+8（共振）
```

一次循环约 0.4–1.2 秒。玩家在第 3 次按压时应该已经理解全部规则。

## 3. 状态机

```
                 ┌──────────────┐
                 │   呼吸相位    │  3.6s 一个周期，只影响光环与共振判定
                 └──────┬───────┘
                        │
  [空闲] ──按下──► [按压中] ──抬起──► [回弹中] ──► [空闲]
     │                  │
     │                  ├─ 命中窗口 ──► 共振：+8、强光、强震、高音
     │                  └─ 未命中   ──► 普通：+1、轻光、轻震、中音
     │
     └─ 点击材质栏 ──► [已解锁] 切换材质 / [未解锁] Toast 提示还差多少星尘
```

- 同一帧最多支持 4 个手指（`pointers` 数组无上限，但凹陷计算是 O(节点 × 手指)）。
- 按在星球正中心时，会拆成**左右对称的两处凹陷**，视觉上更像「整颗被压扁」，而不是歪向一边。

## 4. 数值

### 4.1 呼吸与共振

| 参数 | 值 | 说明 |
| --- | --- | --- |
| `PULSE_PERIOD` | 3.6 s | 一个完整呼吸周期 |
| `RESONANCE_FROM` | 0.58 | 窗口起点（周期百分比） |
| `RESONANCE_TO` | 0.78 | 窗口终点 → 窗口宽度 0.72 s |
| 共振奖励 | +8 星尘 | 普通按压是 +1 |
| 共振舒适度 | +0.26 | 普通按压 +0.07 |

窗口宽 20% 的周期：随手乱点大约 1/5 的概率命中，不需要看屏幕也能偶尔触发——这是刻意的，
**解压游戏不应该要求玩家盯着一个环计时**。

### 4.2 舒适度与表情

- `comfort` ∈ [0,1]，每次按压 +0.07（共振 +0.26），每秒自然衰减 0.02。
- `joy = 0.3 + comfort × 0.72`，驱动笑弧曲率。
- `squint = clamp(形变量 × 3.2, 0, 1)`，被捏时眯眼。
- 眨眼：每 2.4–6.0 秒随机一次，持续 0.17 秒的正弦脉冲。
- 眼珠跟随最近一根手指，偏移上限 2.2% 半径。

### 4.3 软体

| 参数 | 值 |
| --- | --- |
| 节点数 | 132 |
| 凹陷高斯 σ | 0.44 rad |
| 凹陷深度系数 | 0.62 |
| 邻接平滑系数 | 0.24 |
| 半径夹取 | [0.3R, 1.5R] |
| 松手冲量 | 54（设计坐标/秒） |
| 材质刚度 k | 84 – 150 |
| 材质阻尼 c | 6.6 – 9.2 |

按压深度：`clamp((1.12R − d) / 0.92R, 0, 1) × 0.78`。
手指在星球外 12% 半径以内仍然有反应，边缘不会「死掉」。

### 4.4 解锁曲线

| 材质 | 阈值 | 预期到达时间 |
| --- | --- | --- |
| 蜜桃奶冻 | 0 | 立刻 |
| 薄荷云朵 | 150 | 约 2–3 分钟（含每日目标） |
| 星海果冻 | 450 | 约 6–8 分钟 |
| 落日布丁 | 900 | 约 12–15 分钟 |
| 极光沙沙 | 1600 | 约 20 分钟 |

配合每日目标（+40 / +60 星尘），连续 5 天打卡可以把内容全部解锁。
曲线刻意做得「第一次进游戏 3 分钟内必然解锁一次」——这是留存的关键节点。

### 4.5 每日目标

按 `dayIndex` 奇偶交替，纯本地派生，不需要服务端：

| 条件 | 目标 | 奖励 |
| --- | --- | --- |
| 偶数日 | 轻捏 18 / 24 / 30 / 36 下 | 40 星尘 |
| 奇数日 | 呼吸共振 3 / 4 / 5 次 | 60 星尘 |

跨天检测：每 2 秒比对一次日期键，变化则重置进度并 Toast 提示。

## 5. 视觉规范

| 元素 | 规格 |
| --- | --- |
| 设计宽度 | 750 |
| 星球半径 | `min(750 × 0.355, 可用高度 × 0.42)`，上限约 266 |
| 顶栏 | 距安全区 18，高 64 的胶囊 |
| 材质栏 | 5 格，间距 92，半径 30，距安全底 62 |
| 音效按钮 | 半径 26，距左 58 |
| 安全区 | 顶 / 底由 Host 换算成设计坐标 |
| 背景 | 天空渐变 + 3 团极光（`lighter` 混合）+ 54 颗星 + 暗角 |
| 粒子池 | 180 个，覆盖式复用 |

字体只用系统字体栈（PingFang SC / Noto Sans CJK SC / Microsoft YaHei），不打包字体文件。

## 6. 音频

两套实现，音阶完全一致：

| 平台 | 实现 | 资源 |
| --- | --- | --- |
| 浏览器 | WebAudio 振荡器现场合成 | 无 |
| vivo | `qg.createInnerAudioContext()` 播放 | `vivo/src/audio/*.wav`，构建期合成 |

| 音效 | 音阶 | 用途 |
| --- | --- | --- |
| press | C5 + 高八度泛音 | 按压 |
| release | G4 | 松手 |
| resonance | E5 + B5 + E6 叠置 | 共振 |
| unlock | C5 → E5 → G5 琶音 | 解锁 |
| goal | G5 → C6 | 每日目标完成 |

每种音效在 vivo 端准备 **2 个实例轮播**，快速连点不会互相打断。

## 7. 性能

- 单帧绘制：1 次背景渐变 + 3 次极光 + 54 颗星 + 1 条 132 节点贝塞尔轮廓 + ~180 粒子。
- 中端机（骁龙 6 系 / 天玑 700 级）目标 60fps；低端机允许掉到 30fps，`dt` 已被钳制到 50ms。
- 渐变对象缓存键：`材质id:半径:圆心x:圆心y`，只在切换材质或尺寸变化时重建。
- 无 GC 压力：软体、粒子全部用定长 `Float32Array` / 对象池。
